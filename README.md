# Abhinav Jain — Portfolio

Personal portfolio website showcasing my software engineering experience, projects, and technical work across AI systems, developer tooling, web development, and infrastructure.

Built with React, Vite, Tailwind CSS, Framer Motion, and components inspired by [React Bits](https://reactbits.dev/).

## Overview

This site is designed as an interactive portfolio rather than a static résumé.

It includes:

- Professional experience and project timelines
- Interactive project and experience cards
- Detailed project views and case studies
- Responsive desktop and mobile layouts
- Animated UI and transitions
- Project metrics, technical stacks, demos, and links
- Contact form integration
- Dark, minimal visual design

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React
- React Bits
- JavaScript / JSX

## Getting Started

Clone the repository:

```bash
git clone https://github.com/issabhiii/Website-V2.git
cd Website-V2
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Vite will display the local development URL in your terminal.

## Available Scripts

Start the development server:

```bash
npm run dev
```

Build the site for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

Run ESLint:

```bash
npm run lint
```

## Design

The portfolio uses an interactive card-based interface built around my engineering work rather than reproducing my résumé directly.

The design focuses on:

- Clear visual hierarchy
- Minimal navigation
- Responsive layouts
- Smooth, purposeful motion
- Interactive experience and project exploration
- Technical depth through metrics, architecture, demos, and implementation details

## Experience

Professional experience is presented through an interactive timeline.

On desktop, experiences can expand into detailed views containing project context, technical decisions, metrics, architecture, screenshots, and demos.

On smaller screens, the interface adapts to compact timeline cards with mobile-friendly expanded views.

## Projects

Projects include developer tooling, browser security, AI systems, and infrastructure work.

Each project can include:

- Technical overview
- Architecture and implementation details
- Technologies used
- Screenshots and demos
- Engineering challenges
- Metrics and outcomes
- Source code or project links where available

## Responsive Design

The interface adapts across device sizes:

- **Desktop** — Timeline layouts, project grids, and expanded detail panels
